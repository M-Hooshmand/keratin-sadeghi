# پنل مدیریت سالن کراتین خانم صادقی

نرم‌افزار مدیریت مشتریان، نوبت‌دهی، ثبت نتیجه کار، مصرف مواد و حسابداری سالن کراتین و پروتئین تراپی.

## امکانات

- ثبت نوبت با نام، نام خانوادگی، شماره تماس، خدمت، تاریخ شمسی، ساعت و بیعانه
- قرار گرفتن خودکار نوبت جدید در «لیست انتظار»
- جستجو و فیلتر نوبت‌ها بر اساس وضعیت (در انتظار، انجام‌شده، لغو‌شده)
- ویرایش تاریخ، ساعت، خدمت، بیعانه و اطلاعات مشتری؛ لغو و بازگردانی نوبت
- ثبت نتیجه نهایی: خدمت انجام‌شده، تاریخ، طول مو (سانتی‌متر)، مشکل مو، شرح کار و مبلغ نهایی
- ثبت مصرف مواد به میلی‌لیتر با قیمت هر میل و محاسبه زنده هزینه مواد و سود
- حسابداری سالانه و ماهانه شمسی: درآمد، هزینه مواد، سود و تعداد کار، همراه با تفکیک خدمت و ماده
- دفترچه مشتریان با پرونده و سابقه کامل نوبت‌ها و نتایج
- تاریخ شمسی با الگوریتم رسمی جلالی، نمایش روز هفته و تعطیلات

## اجرا

پیش‌نیاز: Node.js نسخه ۲۰ یا بالاتر.

```bash
npm install
npm run dev
```

سپس مرورگر را روی `http://localhost:3000` باز کنید.

برای اجرای نسخه تولید:

```bash
npm run build
npm start
```

این نسخه برای استفاده محلی و تک‌کاربره طراحی شده است. اگر آن را روی سرور عمومی اجرا می‌کنید، دسترسی را با فایروال یا لایه احراز هویت محدود کنید.

## دیتابیس و پشتیبان‌گیری

اطلاعات در فایل `data/keratin.db` (SQLite) ذخیره می‌شود و به‌صورت خودکار ساخته می‌شود. برای پشتیبان‌گیری کافی است هنگام خاموش بودن برنامه از پوشه `data` کپی بگیرید.

برای تغییر مسیر دیتابیس، متغیر محیطی `DB_PATH` را تنظیم کنید.

## قیمت مواد

شش ماده اولیه با قیمت نمونه ساخته می‌شوند. قیمت‌ها را از صفحه «مواد و قیمت‌ها» با قیمت واقعی هر میل جایگزین کنید.

هنگام ثبت نتیجه، قیمت هر میل در همان نوبت ذخیره می‌شود؛ بنابراین تغییر قیمت‌ها در آینده، حسابداری گذشته را تغییر نمی‌دهد.

## تاریخ شمسی و تعطیلات

تبدیل تاریخ به‌صورت محلی و با الگوریتم رسمی جلالی انجام می‌شود و به اینترنت وابسته نیست. تعطیلات رسمی از سرویس `holidayapi.ir` دریافت و در دیتابیس کش می‌شود؛ اگر اینترنت قطع باشد، تقویم بدون تعطیلات نمایش داده می‌شود.

برای استفاده از خروجی `time.ir`، کلید API را در فایل `.env` قرار دهید:

```bash
TIME_IR_API_KEY=your-key
```

در این حالت مسیر `/api/calendar/today` در صورت موفقیت، عنوان مناسبت را از `time.ir` می‌خواند و منبع پاسخ را `time.ir` اعلام می‌کند؛ در غیر این صورت از تقویم محلی استفاده می‌شود.

## ساختار پروژه

- `app/` صفحات و مسیرهای API
- `components/` فرم‌ها، تقویم شمسی و اجزای رابط
- `lib/jalali.ts` تبدیل و قالب‌بندی تاریخ شمسی
- `lib/db.ts` اتصال و ساخت جدول‌های SQLite
- `lib/queries.ts` کوئری‌های مشترک و گزارش‌ها
- `lib/types.ts` نوع‌ها و وضعیت‌ها
- `data/keratin.db` دیتابیس محلی

## مسیرهای API

- `GET/POST /api/appointments` و `GET/PATCH/DELETE /api/appointments/[id]`
- `GET/POST /api/customers` و `GET/PATCH/DELETE /api/customers/[id]`
- `GET/POST /api/visits` و `GET/PATCH/DELETE /api/visits/[id]`
- `GET/POST /api/materials` و `PATCH/DELETE /api/materials/[id]`
- `GET /api/accounting?year=1405`
- `GET /api/holidays?year=1405&month=8`
- `GET /api/calendar/today`
- `GET /api/services`

## بررسی کد

```bash
npm run lint
```

این دستور بررسی نوع‌ها با TypeScript را اجرا می‌کند. ساخت پروژه نیز با `npm run build` انجام می‌شود.
